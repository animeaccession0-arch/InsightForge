# InsightForge

InsightForge is an interactive analytics workspace for product inspection, predictive vending, heritage QC, academic inbound, language learning, sample CSV generation, admin reviews, and multi-agent routing.

## Run locally

This app is built with React, TypeScript, Vite, Tailwind CSS, and Wouter. From the project directory, install dependencies with pnpm, then run the Vite dev script with PORT and BASE_PATH set.

The demo stores datasets, activity, reviews, language selection, and progress in browser localStorage.
