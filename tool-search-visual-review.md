# Tool search visual verification

The desktop sidebar shows the Search tools field and a no-results message for `does-not-exist`. The mobile navigation drawer opens with the same unmatched query and displays the no-results state without horizontal overflow. A separate filtered mobile capture with `language` showed the single Language Lab result, confirming direct result visibility and reachability.

Tool descriptions are now part of the navigation metadata, so searches can match names, keys, or descriptions such as `forecast shocks`. Direct result selection calls the existing workspace selector, and authorized Admin reviews remains included when appropriate.
